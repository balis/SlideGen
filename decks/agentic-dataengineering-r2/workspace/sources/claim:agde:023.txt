CLAIM ID: claim:agde:reproducibility:005
STATEMENT: The embedding model is baked into every stored vector: vectors produced by model version A and vectors produced by version B occupy incompatible geometric spaces, so mixing them makes similarity scores meaningless. Changing the embedding model therefore requires re-encoding the entire corpus and rebuilding the ANN index from scratch — a full re-index — before queries using the new model can be served correctly.

Section: Why model changes require full re-indexing
Type: Web (vendor documentation, Zilliz/Milvus)
Retrieved: 2026-06-15

EXCERPT
-------
"Upgrading embedding models in production vector databases typically necessitates reencoding the entire corpus and rebuilding the Approximate Nearest Neighbor (ANN) index, leading to significant operational disruption and computational cost. When query embeddings are generated by model version B but index embeddings were built with version A, those vector spaces are not compatible and similarity scores become meaningless. A single collection in your database must only contain vectors from the same model, and if you mix them, your search results will be random noise."

EXCERPT
-------
"The coordinate system in a vector database is entirely defined by the embedding model used to populate it, and when you change the embedding model, you are fundamentally changing the geometry of that universe. The most straightforward approach involves building an entirely new index with re-encoded data in parallel, and once the new index is ready and validated, traffic is swapped to it, ensuring optimal performance with the new model but incurring significant recompute cost for the entire corpus."

"Drift-Adapter is a lightweight, learnable transformation layer designed to bridge embedding spaces between model versions, by mapping new queries into the legacy embedding space and enabling the continued use of the existing ANN index. This approach recovers 95-99% of retrieval recall while adding minimal query latency."
