EXCERPT
"text-embedding-3-large is OpenAI's flagship text embedding model, producing 3072-dimensional vectors that can be truncated to smaller sizes via Matryoshka representation learning. Because the model is trained with Matryoshka representation learning, you can pass a smaller dimensions parameter (for example 1024 or 256) to save storage in your vector database with only a modest quality loss."

SUPPORTING CONTEXT
The OpenAI embeddings guide documents that:
- Developers can pass a 'dimensions' parameter at inference time to control output vector size.
- Default output dimensions: 1536 for text-embedding-3-small, 3072 for text-embedding-3-large.
- Quality loss from truncation is described as "modest," making dimension a tuneable dial.
- This feature is only available in models trained with Matryoshka Representation Learning (MRL).
- text-embedding-ada-002 does NOT support dimension truncation.

This confirms that dimension is an explicit model-selection and runtime configuration decision with measurable quality-cost implications.
