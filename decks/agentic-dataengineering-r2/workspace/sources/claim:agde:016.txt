EXCERPT (from DuckDB blog, fetched directly):
"AsOf joins match rows based on nearby values rather than exact equality, making them ideal for temporal analytics. They find 'the value of a property as of a specific point in time' by locating the most recent matching record before a given timestamp."

"DuckDB 'hash partitions and sorts the right hand side to make a temporary state table' during processing, then performs a merge join within each partition."

Syntax from DuckDB documentation:
"FROM holdings h ASOF JOIN prices p ON h.ticker = p.ticker AND h.when >= p.when"
"FROM holdings h ASOF JOIN prices p USING(ticker, 'when')"

"Benchmarks show AsOf joins significantly outperform standard SQL alternatives using window functions and inequality joins—sometimes by 'several orders of magnitude' depending on data characteristics and table sizes."
