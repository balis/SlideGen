"Optimizing for accuracy alone yields agents 4.4-10.8x more expensive than cost-aware alternatives while maintaining comparable performance levels."

"Cost variations of up to 50x can occur for similar precision levels when evaluation lacks cost controls."

"When agents are evaluated across multiple runs rather than single executions, metrics drop substantially—from 60% accuracy in isolated runs to just 25% when assessed for 8-run consistency."

"Expert evaluation (N=15) demonstrated that CLEAR better predicts production success (correlation ρ=0.83) compared to accuracy-focused metrics alone (ρ=0.41)."

The CLEAR framework dimensions:
- Cost: Controlled evaluation preventing wasteful resource allocation
- Latency: Response time performance
- Efficacy: Task completion accuracy
- Assurance: Security and policy compliance metrics
- Reliability: Consistency across multiple executions
